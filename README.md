# 꾸림 PC 프로그램

[꾸림](https://kkurim.kr) 을 PC에서 프로그램으로 쓰는 설치 파일을 두는 곳이에요.

## 내려받기

- **윈도우**: [kkurim-setup.exe](https://github.com/user-wprhks02/kkurim-desktop/releases/latest/download/kkurim-setup.exe)

처음 설치할 때 'Windows의 PC 보호' 창이 뜨면 **추가 정보 → 실행**을 눌러 주세요(아직 코드 서명 전이라 나오는 안내예요).

## 되는 것

- 창을 닫아도 트레이에 남아 알림 받기 (트레이 메뉴에서 '프로그램 끝내기'로 바꿀 수 있어요)
- 컴퓨터를 켤 때 자동 실행
- 새 요청·멘션·채팅 PC 알림, 작업 표시줄 표시
- 새 버전은 저절로 받아 두었다가 프로그램을 끌 때 설치돼요

이 저장소에는 설치 파일만 있어요. 계정·팀 자료는 들어 있지 않아요.
